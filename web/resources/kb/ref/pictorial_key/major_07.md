# major_07 — The Chariot
Source: https://sacred-texts.com/tarot/pkt/pktar07.htm

## Description
"An erect and princely figure carrying a drawn sword and corresponding, broadly speaking, to the traditional description which I have given in the first part."

## Divinatory meanings
Upright: "He is above all things triumph in the mind." "He has led captivity captive; he is conquest on all planes--in the mind, in science, in progress, in certain trials of initiation."
Reversed: No reversed meaning is given on this page of the source text.
